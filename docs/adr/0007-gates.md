# ADR 0007 — Revisão documental antes da fundação executável

Data: 2026-10-16

Status: Aceita para esta entrega

## Contexto

Seção 25 inclui infraestrutura na Fase 0, enquanto seções 0 e 29 mandam produzir documentos e parar para aprovação.

## Decisão

Dividir Fase 0 em 0A planejamento revisável e 0B fundação executável. A aprovação de 0A não declara o gate de 0B cumprido e não inicia automaticamente a Fase 1.

## Consequências e alternativas

Entrega atual contém documentação. Docker, CI e aplicação permanecem explicitamente pendentes; gate da Fase 0 só fecha com execução real.
